# Technical decisions

- \[architecture\] Todos are stored in a platform-managed PostgreSQL owned by the API service. *assumed* (all)
- \[data-model\] Todo ids are UUIDs generated by the API; the list is ordered by creation time, then id. *assumed* (F1)
- \[todo-api\] The list endpoint pages with a default and maximum of 500, so the app shows the whole list in one request. *assumed* (F1)
- \[todo-api\] Title trimming and length validation happen in the API, and the web app mirrors them for fast feedback. *assumed* (F1)
- \[todo-webapp\] Changes are saved through the API immediately; the list reloads after each change. *assumed* (F1)
